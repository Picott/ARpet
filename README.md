# Holopet · mascota holográfica inteligente (prototipo)

Prototipo funcional de una mascota holográfica que vive en un pedestal pequeño de escritorio,
más la especificación de hardware de la versión física.

**Cómo usarlo:** abre `index.html` en Chrome o Edge (doble clic basta; no hay backend ni llaves de API).
Necesita conexión solo para descargar Three.js desde la CDN.

- Chat de texto y voz (Web Speech API), botones de acariciar / alimentar / jugar / dormir.
- Personalidad, memoria en `localStorage`, estados internos, proactividad, evolución por etapas.
- Comandos: `/nombre`, `/especie`, `/color`, `/feral` (con palabra definible), `/fiesta`, `/pedestal`, `/estado`, `/olvidar`, `/ayuda`.
- Botón **Versión física**: opciones de display, sensores, procesamiento local y coste estimado.
